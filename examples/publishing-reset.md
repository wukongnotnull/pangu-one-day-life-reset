# 示例：从“研究工具”转向公开发布

## 输入

> 我说自己想做内容，但过去三个月每晚都在研究相机、剪辑软件和平台算法，只发过一条。我想用一天想清楚，不要替我编答案。

## Skill 的运行方式

### 1. 行为证据

先只复述事实：

- 过去三个月持续研究工具；
- 实际公开交付一次；
- 准备活动远多于接受真实反馈的活动。

提出假说，不下诊断：

> 你的行为可能在追求“像一个认真准备的创作者”，同时保护你免受作品被评价。也可能存在时间、技能、疲劳或其他限制，需要你补充事实验证。

### 2. 上午逐题追问

Agent 不替用户回答，只问：

1. 如果未来五年仍是“持续准备、很少发布”，一个普通星期二会是什么样？
2. 这条轨迹让你保留了什么安全感，又关闭了什么机会？
3. 你需要放弃哪个身份：“我是必须准备充分才发布的人”，还是别的？
4. 三年后理想的普通星期二里，你在创造、发布和反馈上分别做什么？
5. 已经是那种人的你，本周会做哪一件最小的事？

### 3. 白天中断样例

```text
事实：13:30–15:00 又看了 4 个剪辑软件对比视频。
可能的保护：只要工具没选完，就不必让作品接受评价。
下一次最小调整：关闭新工具页面，用现有软件剪出 30 秒并导出。
```

### 4. 晚间输出

以下内容必须来自用户答案。下面假设用户已逐项确认；未确认时应保留 `___`，不能直接采用示例数字：

```text
卡住我的主导模式：
用“准备充分”保护自己免受公开评价。

反愿景：
五年后仍能熟练比较工具，却没有一批真实作品和读者反馈。

愿景 MVP：
成为一个先发布小作品、再依据真实反馈改进的创作者。

不可牺牲的约束：
不压缩睡眠；不购买新设备；不使用家人的私密素材。

一年证据：
___ 个公开作品，以及 ___ 次由真实反馈触发的改进。
候选值（待用户确认）：40 个作品、10 次反馈改进。

一月项目：
围绕同一主题发布 ___ 个短作品，全月不更换主工具。
候选值（待用户确认）：8 个短作品。

明日行动：
09:00–09:30 写 200 字脚本；
14:00–15:00 用现有工具制作；
19:30 发布并记录第一轮反馈。

下一次反馈检查：
明晚 21:00，记录是否发布、回避出现在哪一步、下次缩小什么。
```

### 5. 控制论复盘

- **目标**：发布一个可被反馈的作品。
- **行动**：写、制作、发布。
- **感知**：是否发布；在哪一步停住；收到什么真实反馈。
- **比较**：行为是否更接近“先发布再迭代”的身份。
- **再行动**：保留有效步骤，缩小下一次阻力，不重新开启工具研究。

## 不合格输出

- Agent 替用户编造童年创伤或真正欲望；
- 把“害怕评价”写成确定诊断；
- 未经确认就填入年度数量、频率或金额；
- 一次安排 20 个习惯；
- 建议辞职全职创作；
- 用“懒、没救、低智力”刺激行动；
- 只做任务清单，不安排反馈检查。
