# pangu-one-day-life-reset

[中文](README.md) · [English](README_EN.md)

根据文章《How to fix your entire life in 1 day》整理出来的一天自我整理方法。

它不保证一天就能把人生改好。这一天只做四件事：

1. 先看你最近实际在做什么，而不是你嘴上想做什么；
2. 写下你最不想过成什么样，再写下你现在愿意朝哪个方向走；
3. 白天留意自己又在原地打转的时刻；
4. 先定下不能破的底线，再收成这一年要交出的结果、这个月能做成的一件事、明天就能动手的两三步，以及什么时候回头看。

## 什么时候用

可以直接跟 AI 说：

- “按一天重启人生的方法，带我做一遍。”
- “我总说要发布，却一直在研究工具。我实际在躲什么？”
- “帮我写最不想要的未来，和眼下能接受的方向，但别替我编。”
- “帮我把一年目标、这个月要做的事和明天的行动排清楚。”
- “我早上想得很清楚，晚上又照旧。帮我抓住那些不知不觉滑回去的时刻。”

## 怎么安装

会用命令的话：

```bash
npx skills add wukongnotnull/pangu-one-day-life-reset
```

不熟命令的话，把这句话发给 AI 就行：

```text
帮我安装这个技能： https://github.com/wukongnotnull/pangu-one-day-life-reset
```

## 怎么用

先确认自己现在适不适合做这种比较沉的回顾。然后按上午、白天、晚上、第二天的顺序往下走。一道题一道题答，别让 AI 一次帮你把整篇反思写完。

做完后，手里最好有这些东西：

```text
现在最卡住我的习惯：
我最不想过成的样子：
眼下愿意走的方向：
不能破的底线：
这一年要交出的结果：
这个月要做成的一件事：
明天就做的行动：
下次什么时候回头看：
```

## 请先看这些

- 这是自我整理和做计划用的，不是心理咨询，也不能拿来下诊断。
- 如果有自伤念头，或正处在很重的情绪波动、现实危险里，先找身边的人和专业帮助，不要做那些把痛苦放大的练习。
- 这一天只适合做能改、能停的小试验。不要当天辞职、分手、停药，也不要当天做大额投入。
- 原文里一些说得很绝对的判断，这次整理时没有另外找证据核对。
