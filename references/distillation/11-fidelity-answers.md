## Q3 — 已知立场：控制论与游戏

**问题**：Explain how anti-vision, vision, one-year goal, one-month project, daily levers, and constraints fit the goal–action–sense–compare–act loop. Give the default order.

**回答**

The framework has two layers: design the control system, then run it.

### Control-system design

1. **Anti-vision:** The unacceptable trajectory—what is at stake.
2. **Vision MVP:** The provisional win condition. It may change with experience.
3. **Constraints:** The rules defining what actions are not allowed to sacrifice.
4. **One-year evidence:** One observable reference point showing that the old pattern has been broken.
5. **One-month project:** The intermediate deliverable that keeps the annual evidence possible.
6. **Daily levers:** Two or three actions that directly advance the monthly project.

In game terms:

- Vision = how you win.
- Anti-vision = what is at stake.
- One-year evidence = the mission.
- One-month project = the boss fight.
- Daily levers = the quests.
- Constraints = the rules.

### Operating loop

1. **Goal:** Select the relevant reference—usually today’s lever serving the monthly project.
2. **Act:** Execute the time-blocked lever.
3. **Sense:** Record what actually happened.
4. **Compare:** Compare the result with the project, annual evidence, vision, anti-vision, and constraints.
5. **Act again:** Keep, shrink, replace, or reschedule the next action.

Correct the shortest-feedback layer first. One failed day usually calls for adjusting the next action, not rewriting the entire vision.
