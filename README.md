# pangu-one-day-life-reset

从《How to fix your entire life in 1 day》蒸馏出的可运行 Skill。

它不承诺一天修好人生，而是用一天完成四件事：

1. 用行为证据识别当前轨迹与可能的保护性目标；
2. 写出具体反愿景和可修订的愿景 MVP；
3. 用全天中断观察自动驾驶；
4. 先写约束，再压缩为一年证据、月度项目、明日行动和反馈时间。

## 触发示例

- “按一日人生重启协议带我做一遍。”
- “我总说想发布却一直研究工具，行为说明我真正想要什么？”
- “帮我写反愿景和愿景 MVP，但不要替我编答案。”
- “把我的一年目标、月项目和明日行动组织成人生游戏。”
- “我早上想得很清楚，晚上又照旧，帮我打断自动驾驶。”

## 安装步骤

### 方式一：技术人员使用 npx skills 安装

```bash
npx skills add wukongnotnull/pangu-one-day-life-reset
```

### 方式二：文科生使用对话方式安装

```text
帮我安装该skill： https://github.com/wukongnotnull/pangu-one-day-life-reset
```

## 使用方式

激活后从安全门开始，再按上午、白天、晚间、次日启动推进。最好逐题完成，不要让 Agent 一次性代写全部反思。

最终应得到：

```text
卡住我的主导模式：
反愿景：
愿景 MVP：
不可牺牲的约束：
一年证据：
一月项目：
明日行动：
下一次反馈检查：
```

## 重要边界

- 这是反思和计划工具，不是治疗或诊断。
- 有自伤风险、严重抑郁、躁狂、精神病性症状或现实危险时停用增压练习。
- 一日协议只推动可逆实验，不推动当天辞职、分手、停药或大额投入。
- 文章中的绝对心理学主张未经过本次蒸馏的外部核验。
